# Glossary

**Startpage**
The single page the user opens as their browser homepage. It shows every Panel arranged in columns and rows.

**Group**
A named set of Panels, shown as a tab across the top of the Startpage (for example "Personal" or "Work"). Every Panel belongs to exactly one Group. Only one Group is shown at a time. There is always at least one Group.
_Avoid_: tab, page. "Tab" is confused with a browser tab. It describes how a Group is displayed, not what it is.

**Panel**
A titled, colored box on the Startpage that holds an ordered list of Links. Has a title, a background color and (optionally) a text color. Panels can be re-ordered among themselves.
_Avoid_: section, column. Columns and rows describe how Panels are laid out, not a separate concept.

**Link**
A named shortcut to a URL, belonging to exactly one Panel. Has a display name and a URL. Can be re-ordered within its Panel or moved to another Panel.
_Avoid_: bookmark.

**Edit mode**
A page-wide state, toggled by the user, in which Panels can be re-ordered by drag and drop and each Panel and Link shows its edit controls. Outside Edit mode the Startpage is for browsing only.

**Export / Import**
Saving the whole Startpage (all Panels and Links) to a JSON file, and loading such a file back.
